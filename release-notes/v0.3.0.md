v0.3.0 makes Jellyui installable like a normal desktop app: a `.dmg` for macOS, an install script with a desktop launcher for Linux, and a new app icon.

## Install

**macOS** (Apple Silicon, macOS 11 or newer): download `jellyui-v0.3.0-darwin-arm64.dmg`, open it and drag Jellyui to Applications. The app isn't notarized, so macOS blocks the first launch. Open it once, then choose **Open Anyway** in System Settings → Privacy & Security, or run:

```sh
xattr -dr com.apple.quarantine /Applications/Jellyui.app
```

**Linux** (x86_64, glibc 2.35 or newer): download the install script, read it, then run it. It checks the download against `checksums.txt` and installs Jellyui with a desktop launcher and icon under `~/.local`.

```sh
curl -fLO https://raw.githubusercontent.com/iamd3vil/jellyui/v0.3.0/scripts/install.sh
less install.sh
sh install.sh
```

`sh install.sh --uninstall` removes it again and keeps your settings. See `sh install.sh --help` for a system-wide install or installing a tarball you already downloaded.

The plain `.tar.gz` archives are still published for both platforms.

## What's new

- **macOS app:** `Jellyui.app` in a drag-to-Applications disk image, with its icon in the Dock and Finder.
- **Linux installer:** `scripts/install.sh` adds Jellyui to your app menu, and the window now matches the launcher, so docks and task switchers show the icon.
- **App icon:** a violet jelly drop with a play button.
