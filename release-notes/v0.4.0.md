v0.4.0 remembers your audio and subtitle choices, and the install script now covers macOS as well as Linux.

## What's new

- **Remembered tracks:** pick a subtitle or audio track and Jellyui uses it again the next time you play that video. The choice is stored by your Jellyfin server, so it also carries over to the Jellyfin web app and other clients. Videos you haven't played start with your Jellyfin language preferences. This needs "Remember audio selections" and "Remember subtitle selections" in your Jellyfin playback settings, which are on by default.
- **Fix:** earlier versions cleared the tracks Jellyfin had remembered every time they reported playback progress.
- **Install script on macOS:** `install.sh` installs `Jellyui.app` on Apple Silicon Macs, into `/Applications` or `~/Applications`.
- **KDE:** the app menu shows Jellyui's icon right after installing, without logging out.

## Install

Download the install script, read it, then run it. It checks the download against `checksums.txt`.

```sh
curl -fLO https://raw.githubusercontent.com/iamd3vil/jellyui/v0.4.0/scripts/install.sh
less install.sh
sh install.sh
```

- **Linux** (x86_64, glibc 2.35 or newer): installs Jellyui with a desktop launcher and icon under `~/.local`.
- **macOS** (Apple Silicon, macOS 11 or newer): installs `Jellyui.app`. Downloads made with curl aren't quarantined, so it opens without the Gatekeeper prompt.

`sh install.sh --uninstall` removes it again and keeps your settings. See `sh install.sh --help` for other options.

You can also download `jellyui-v0.4.0-darwin-arm64.dmg` and drag Jellyui to Applications. The app isn't notarized, so macOS blocks the first launch: choose **Open Anyway** in System Settings → Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Jellyui.app`. The plain `.tar.gz` archives are still published for both platforms.
